StoryTeller privacy notice

Provider: Irina Novikova, operating as StoryTeller, residing in Thailand. Contact: admin@donttellmeyourstory.com.

Jira reporting

StoryTeller processes Jira information to build a snapshot requested by the signed-in user. It reads accessible project and favourite-filter metadata, Jira server information, issue identifiers, summaries, statuses, assignee information and due dates. These fields may contain personal information. Each request uses the caller’s Jira permissions, and the selected source is revalidated when a report is generated. The provider processes the requested report for the customer’s chosen purpose; the customer controls which Jira source is used.

Working drafts, exports and historical records

The current app keeps report snapshots and author edits in page memory. It does not write reports to an application database or browser local storage. Refreshing or leaving discards the working draft. This describes current app behavior, not all browser or Atlassian platform records. Downloaded HTML and printed PDFs contain static data; their holders control access, sharing and deletion. Uninstalling the app does not recall exported files.

Earlier development versions could save a Rovo narrative in Forge storage and prompt templates in browser local storage. The current version does not read or write those records. Historical deletion has not been verified; this notice does not claim that all records from earlier versions have been erased.

Atlassian services and optional Rovo

Atlassian hosts the app on Forge and provides Jira. Platform operational records, backups, processing locations and subprocessors follow the applicable Atlassian service arrangements. StoryTeller does not promise that all processing occurs in a particular country.

Report generation does not require AI. If you choose Open Rovo with counts, the app opens a separate Atlassian chat with aggregate counts and completeness in the initial prompt. It excludes issue text, people, source names, links and author notes from that prompt. Rovo may process later messages and other context under Atlassian’s terms and your organization’s settings. Atlassian may use external model providers; organization data-contribution settings may permit Atlassian to use Rovo conversations for product and AI improvement. StoryTeller does not control those settings.
