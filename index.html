StoryTeller support

Contact StoryTeller at admin@donttellmeyourstory.com for support, privacy requests or security reports. Include the app version, browser, steps to reproduce, expected/actual result and a redacted error message. Do not send passwords, tokens, unredacted Jira exports or unnecessary personal data. Use synthetic examples where possible.

  1. Open StoryTeller from Jira Apps after an administrator has installed an approved release.
  2. Select Project or Favourite saved filter. Search and refresh project choices as needed. Choose your source and verify the report timezone.
  3. Select Create report. Check source, snapshot date and coverage before relying on a finding. A partial report is not the full project. Unknown status categories and unusable due dates limit conclusions.
  4. Review the generated slides. Title limit: 80 characters. Optional notes/actions: 220 characters and three lines each. Notes are labelled unverified author text.
  5. Choose Editorial or Midnight. Download HTML or use Print / Save PDF. If Jira blocks printing, open the downloaded HTML in a browser and print there. Download before leaving the app.
  6. Optional Rovo is separate from report generation. Review any suggestion yourself; it never automatically changes the report. Rovo availability depends on the Atlassian site.

Troubleshooting: No choices can mean no accessible projects or no favourite saved filters. Refresh choices and verify access in Jira. Permission errors require the site's administrator to review the existing access; the app cannot bypass it. A request-limit message means wait and retry. A failed page rejects generation rather than silently exporting a successful report. For partial coverage, narrow the source using an existing suitable filter. A mismatch between status names and report status groups can reflect Jira's status-category configuration. Due dates are compared with the calendar date in the chosen timezone; due today is not past due.
